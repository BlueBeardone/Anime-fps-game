# Main Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a startup main menu (Campaign, Multiplayer, Range, Settings, Exit) that drops the player into the existing empty `Main` scene as a single-player session.

**Architecture:** A new `MainMenu.unity` scene (build index 0) holds a `MainMenuController` that builds a runtime uGUI overlay, matching the project's existing `HostJoinMenu` pattern. `Main` becomes build index 1 and auto-starts a solo local host through `NetworkBootstrap`, so the existing networked player prefab works unchanged and no host/join UI is shown.

**Tech Stack:** Unity 6000.6.9f1, URP, Input System, uGUI (runtime-built), Netcode for GameObjects 2.14.0, Unity Test Framework (PlayMode).

**Spec:** `docs/superpowers/specs/2026-11-16-main-menu-design.md`

## Global Constraints

- Unity editor: `E:\Unity\Editors\6000.6.9f1\Editor\Unity.exe`; project: `D:\Making Games\Anime fps game`.
- uGUI + Input System only; no legacy `Input` API.
- Runtime code lives in the `AnimeFpsGame.Runtime` asmdef (`Assets/_Project/Scripts/AnimeFpsGame.Runtime.asmdef`).
- No git repository: verification checkpoints replace commits; never delete assets without a check.
- `ProjectSetup.cs` must stay idempotent and must keep `MainMenu` at build index 0, `Main` at index 1.
- Do not rebuild `Player.prefab`; it contains hand-tuned values.
- Scene edits go through `ProjectSetup` edit-mode methods, not hand-edited YAML, whenever practical.

## Review Focus

- Campaign and Multiplayer must be visibly dimmed and impossible to click or keyboard-select.
- Settings must be clickable, do nothing, and never change the active scene or throw.
- The menu must reuse an existing `EventSystem` instead of creating a duplicate module.
- Build index 0 must always be `MainMenu`, index 1 `Main`.
- Entering Range must show no Host/Join UI and must spawn the player without any click.

using System.Collections;

using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.SceneManagement;
using UnityEngine.TestTools;
using UnityEngine.UI;

namespace AnimeFpsGame.Tests
{
    public class MainMenuTests
    {
        GameObject menuObject;

        [TearDown]
        public void TearDown()
        {
            if (menuObject != null)
            {
                Object.Destroy(menuObject);
            }

            foreach (var canvas in Object.FindObjectsByType<Canvas>(FindObjectsSortMode.None))
            {
                Object.Destroy(canvas.gameObject);
            }

            foreach (var eventSystem in Object.FindObjectsByType<EventSystem>(FindObjectsSortMode.None))
            {
                Object.Destroy(eventSystem.gameObject);
            }
        }

        [UnityTest]
        public IEnumerator MenuBuildsTheFiveExpectedButtons()
        {
            menuObject = new GameObject("Menu", typeof(MainMenuController));
            yield return null;

            var menu = menuObject.GetComponent<MainMenuController>();
            Assert.AreEqual(5, menu.Buttons.Length);
            CollectionAssert.AreEqual(
                new[] { "CAMPAIGN", "MULTIPLAYER", "RANGE", "SETTINGS", "EXIT" },
                menu.Buttons.Select(button => button.name).ToArray());
            Assert.IsFalse(menu.GetButton("CAMPAIGN").interactable);
            Assert.IsFalse(menu.GetButton("MULTIPLAYER").interactable);
            Assert.IsTrue(menu.GetButton("RANGE").interactable);
            Assert.IsTrue(menu.GetButton("SETTINGS").interactable);
            Assert.IsTrue(menu.GetButton("EXIT").interactable);
            Assert.AreSame(menu.GetButton("RANGE").gameObject, EventSystem.current.currentSelectedGameObject);
        }

        [UnityTest]
        public IEnumerator SettingsClickKeepsTheCurrentScene()
        {
            menuObject = new GameObject("Menu", typeof(MainMenuController));
            yield return null;

            var menu = menuObject.GetComponent<MainMenuController>();
            var sceneBefore = SceneManager.GetActiveScene().name;
            menu.GetButton("SETTINGS").onClick.Invoke();
            yield return null;

            Assert.AreEqual(sceneBefore, SceneManager.GetActiveScene().name);
        }

        [UnityTest]
        public IEnumerator MenuReusesAnExistingEventSystem()
        {
            var existing = new GameObject("ExistingEventSystem", typeof(EventSystem),
                typeof(UnityEngine.InputSystem.UI.InputSystemUIInputModule));
            menuObject = new GameObject("Menu", typeof(MainMenuController));
            yield return null;

            Assert.AreEqual(1, Object.FindObjectsByType<EventSystem>(FindObjectsSortMode.None).Length);
            Object.Destroy(existing);
        }
    }
}
