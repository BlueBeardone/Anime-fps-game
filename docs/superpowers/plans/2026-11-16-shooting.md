# Shooting, Reloading and Damage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the shoot log with four raycast gun archetypes behind one contract, with bloom, learnable spray, reloading, server-validated damage, dummies, HUD and shot feedback.

**Architecture:** Pure C# `IGun`/`Gun` classes own ammo, cadence, reload, bloom and spray. `PlayerWeapons` owns one gun instance per serialized slot (state survives swaps), handles input, viewmodel feel, local raycasts and network RPCs. ScriptableObject stats assets keep tuning alive across `Run All`. Damage is server-authoritative; ammo stays owner-side.

**Tech Stack:** Unity 6000.6.9f1, URP, Input System 1.20.1, Netcode for GameObjects 2.14.0, NUnit via Unity Test Framework.

## Review Focus

- **Weapon switch during reload:** switching away and back must not finish the old reload on the new gun or reset ammo. Pinned in Task 1 (`CancelReloadKeepsAmmo`) and Task 4 (ammo survives `SetSlot`).
- **Held trigger on the last round:** full-auto holding fire on an empty magazine must start exactly one reload, not a loop. Pinned in Task 1 (`AutoReloadStartsOnceWhenEmpty`).
- **Shotgun pellet accounting:** all 8 pellets must share the configured per-pellet damage and stay inside the cone; a single pellet must not deal the full 8-pellet total. Pinned in Task 2 (`ShotgunEmitsConfiguredPelletsWithinCone`, `ShotgunDamageIsPerPellet`).
- **Partial reserve:** reloading with fewer reserve rounds than the magazine needs must load only what exists. Pinned in Task 1 (`PartialReserveLoadsOnlyAvailable`).
- **Death rules:** damage at zero must fire `Died` once, ignore further damage while dead, and revive fully. Pinned in Task 3 (`HealthStateClampsAndDiesOnce`, `HealthStateIgnoresDamageWhileDead`).

- [ ] **Step 3: Implement the contract and `Rifle`**

- `Gun` stores the shared state (`ammo`, `reserve`, `isReloading`, `reloadRemaining`, `nextFireTime`, `bloom`, `timeSinceLastShot`, `sprayIndex`, events). Cadence is `60f / Stats.roundsPerMinute`; `FullAuto` requires `triggerHeld`, `SemiAuto` requires `triggerPressed`. A successful shot decrements ammo, resets `timeSinceLastShot`, raises `RecoilKicked` (zero for now), raises `AmmoChanged`, and calls `TryStartReload()` when ammo reaches 0 with reserve left. `Tick` counts the reload down and completes it with `min(magazineSize - ammo, reserve)`. `ResetAmmo` refills magazine and reserve, cancels reload and clears bloom/spray. Emit `AmmoChanged`/`ReloadStateChanged` on every state change.
- For now `BuildDirections` returns one normalized `aimForward`; bloom and pellets arrive in Task 2.
- `Rifle.CreateDefaultStats()` returns the spec values from the rifle column (600 RPM, 24 damage, 1 pellet, 30/120, 2.2 s, 0.25° base, 0.35° bloom, 3.5° max, 8°/s recovery, 0.4 s spray reset, display name `Rifle`, archetype `Rifle`, fire mode `FullAuto`). Its `SprayPattern` starts with `(0,0)` and is a 30-entry rising pattern; the exact curve is tuning and may be replaced later.

- [ ] **Step 3: Implement bloom, spray and archetypes**

- `Gun`: effective spread is `baseSpread + bloom`; add bloom on each shot clamped at max; in `Tick`, after 0.15 s without firing, reduce bloom by `bloomRecoveryDegreesPerSecond * deltaTime`; reset the spray index to 0 once `timeSinceLastShot > sprayResetSeconds` and whenever a reload starts or completes.
- Spray: keep cumulative pattern offsets. On a shot take `pattern[min(index, last)]`, subtract the previous point (or zero), raise `RecoilKicked` with the delta, then advance the index (clamped). Patterns start at `(0,0)`.
- Directions: for each pellet, pick `Random.insideUnitCircle * spread` (degrees) and rotate `aimForward` with `Quaternion.Euler(-offset.y, offset.x, 0f)`. Spread is `pelletSpreadDegrees` when `Stats.pellets > 1`, otherwise `CurrentSpreadDegrees`.
- `Handgun.CreateDefaultStats()`: SemiAuto, 400 RPM, 30 damage, 12/60, 1.5 s, 0.20° base, 0.70° bloom, 3.0° max, 8-step pattern, `Handgun` archetype, display name `Handgun`.
- `SubmachineGun.CreateDefaultStats()`: FullAuto, 900 RPM, 18 damage, 32/160, 1.8 s, 0.50° base, 0.45° bloom, 5.0° max, 32-step pattern, `SubmachineGun`, display name `SMG`.
- `Shotgun.CreateDefaultStats()`: SemiAuto, 70 RPM, 9 damage, 8 pellets, 6/24, 2.6 s, 2.5° base, 3.0° pellet spread, 1.0° bloom, 6.0° max, pattern `{ Vector2.zero, new Vector2(0f, 2f) }`, `Shotgun`, display name `Shotgun`.
- `GunFactory.Create` switches on `stats.archetype` and constructs the matching class; throw `System.ArgumentOutOfRangeException` for an unknown archetype.

- [ ] **Step 3: Implement `HealthState`, `IDamageable` and `Health`**

- `HealthState.ApplyDamage` clamps the amount at ≥0, subtracts, clamps at 0, and returns true only when the target was alive before and is dead after. It returns false when already dead. `Revive` restores `Max` and clears dead.
- `Health` keeps `[SerializeField] float maxHealth = 100f`, `[SerializeField] bool ignoreOwnerDamage = true`, a server-written `NetworkVariable<float> currentHealth`, and a server-written `NetworkVariable<bool> isDead` (read permission Everyone). On network spawn the server sets current health to `maxHealth` if this is the first value. `ApplyDamage` returns early unless `IsServer`, the target is alive, and (when `ignoreOwnerDamage`) `attackerClientId != OwnerClientId`. It updates the `NetworkVariable`s and fires `Died`/`DeathStateChanged` when death flips true (once). Dummies set `ignoreOwnerDamage = false` because scene `NetworkObject`s are server-owned.
- On every peer, `DeathStateChanged` toggles all child `Collider`s and the root `CharacterController` (`enabled = !dead`). Do not touch renderers here; visuals are owned by `PlayerWeapons`, `TargetDummy` and the respawn flow.
- `Revive` is server-only: full health, `isDead = false`.
